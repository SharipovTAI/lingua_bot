# Вторая неделя

Исполнитель: Шарипов Тимур Илгизович. Период: 02.11–08.11.2026.

## Реализовано

1. Регистрация по email, проверка пароля, сохранение хеша средствами Django.
2. Вход с токеном, выход с отзывом токена и ограничение частоты входа/регистрации.
3. Просмотр и изменение собственного профиля: уровень, цель обучения, язык en.
4. Создание собственных диалогов, их список и получение одного диалога.
5. Сохранение сообщений пользователя, загрузка истории из SQLite.
6. Проверка доступа: без токена — 401, чужой диалог — 404 при чтении и записи.
7. Актуальная схема OpenAPI, контракт и пример клиента для React.

Для локальной ручной проверки есть `/dev/week2/` (только при DEBUG=true).
Это техническая страница бэкенда, а не реализация экранов React.
Ответы ИИ и исправления ошибок пока не генерируются — они относятся к неделе 3.

## Фронтенд

Изучена ветка origin/frontend, коммит adabec0. В ней есть каркас интерфейса
и главная страница, остальные разделы — PlaceholderPage. Запросов авторизации
и чата пока нет. Бэкенд-контракт и пример клиента подготовлены для подключения;
полная интеграция с экранами React ещё не выполнена.

## Проверки

34 теста Django: авторизация, валидаторы, хеширование пароля, профиль, сохранение
сообщений, разделение данных, отзыв токена, CORS и отсутствие платных вызовов.
`manage.py check`, `makemigrations --check --dry-run` и валидация OpenAPI.
Для отчёта отдельно проверены реальные HTTP-запросы в браузере. После остановки
и повторного запуска процесса сервера история из двух сообщений восстановлена
с прежними идентификаторами и временем создания. Пример клиента для React проверен
реальными запросами входа, чтения профиля и истории, выхода. Данные тестовых токенов
не включены в отчёт, сами токены отозваны.
