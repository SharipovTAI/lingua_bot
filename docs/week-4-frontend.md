# Интерфейс четвёртой недели

React-клиент к API четвёртой недели. Ветка `frontend` содержит историю `main`
и интерфейс поверх неё. Контракт бэкенда: [week-4-api.md](week-4-api.md).

## Экраны и запросы

| Маршрут | Экран | Запросы |
| --- | --- | --- |
| `/placement` | Входной тест: 10 вопросов, шкала A1–C1, результат | `GET/POST /api/v1/placement/` |
| `/exercises` | Упражнения уровня, фильтр grammar/vocabulary, проверка ответа | `GET /exercises/`, `POST /exercises/{id}/attempts/` |
| `/dictionary` | Личный словарь, добавление/правка/удаление, карточки повторения | `/vocabulary/`, `/vocabulary/review/`, `/vocabulary/{id}/reviews/` |
| `/` | Дашборд: уровень, серия, задания дня, график, сводка, достижения | `GET /statistics/`, журнал действий |
| `/progress` | Точность, попытки, разбивка по типам, входной тест, график | `GET /statistics/` |
| `/achievements` | Витрина достижений и прогресс | `GET /statistics/`, журнал действий |

Все запросы записи отправляют `request_id` в формате UUID. При сетевой
ошибке клиент повторяет запрос с тем же UUID и тем же телом, поэтому счётчики
не удваиваются. Новый осознанный ответ получает новый UUID.

## Серия и график активности

`GET /statistics/` отдаёт накопленные показатели, но не дневную серию.
Поэтому недельный график, серия дней и задания «на сегодня» строятся по
журналу действий в браузере (`localStorage`, ключ `linguabot_activity_<id>`).
Запись появляется только после успешного ответа API: входной тест, попытка
упражнения, добавление слова, повторение, создание диалога или сообщение.
Все остальные числа (уровень, точность, слова, повторения, тест) приходят из
`/statistics/`. Это указано в подписи под графиком и на экране прогресса.

## Запуск

Django должен быть запущен. В корне проекта:

```powershell
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_scenarios
.\.venv\Scripts\python.exe manage.py seed_exercises
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Во втором терминале:

```powershell
npm install
npm run dev
```

Откройте http://localhost:5173/. В `.env.local` должно быть
`VITE_USE_MOCK=false`. Если Django не нужен, поставьте `VITE_USE_MOCK=true`:
экраны и запросы те же, данные хранятся в браузере.

Демонстрационный аккаунт в локальной SQLite (создан при проверке, можно
удалить): `demo@lingua.local` / `LinguaDemo2026!`. У него уровень C1,
пройденный тест, попытки упражнений и два слова. Для чистого сценария
зарегистрируйте новый аккаунт.
