# API пятой недели

Дата проверки — 27.11.2026. База — /api/v1/. JSON, UTF-8.
Кроме health, scenarios, register и login, все операции требуют
Authorization: Token <токен входа>. Схема — /api/schema/, Swagger — /api/docs/.

## Языки и совместимость

Поддержаны en, de, ru. В PATCH /profile/ можно передать language, level, goal.
Смена языка восстанавливает последний уровень этого языка. У нового языка
уровень A1. goal относится к аккаунту, уровень — к выбранному языку.
Profile.level сохраняется как совместимое поле текущего уровня.
LanguageProgress хранит независимые значения.

Старые диалоги, упражнения, слова и результаты мигрируют как английские.
Новая переписка получает язык профиля при создании диалога.
Смена профиля не изменяет язык существующего разговора.
GET /conversations/ показывает разговоры выбранного языка.
GET /conversations/{id}/ и /messages/ доступны владельцу по прежним ID.

Миграции 0003/0004 сохраняют существующие записи. Для старого словаря неизвестная
дата добавления остаётся null, такие слова не добавляются искусственно в график.

## Диалог

POST /conversations/ — прежнее тело scenario_id. Ответ дополнен language.
GET /scenarios/ возвращает 10 ситуаций. Их инструкции работают для трёх языков.

POST /conversations/{id}/messages/:

~~~json
{"content":"Ich möchte ein Tee.","request_id":"b7fe51c3-e72c-4108-8576-39c9b07c704f"}
~~~

UUID рекомендуется для клиента, старые вызовы без него поддерживаются.
Успех — 201, повтор с тем же UUID и текстом — 200 с прежней парой сообщений.
Другой текст с прежним UUID — 400. Повтор до завершения текущего платного вызова
может получить 409: ассистент занят. Подождите и повторите с прежним UUID.
В демонстрационном однопроцессном сервере вызовы модели сериализуются Lock.
Для нескольких процессов потребуется общее хранилище блокировок и ограничителей.

Модель вызывается через Apimira с tools/tool_choice и функцией tutor_response.
Это решает проблему обычных текстовых ответов при запросе JSON.
response_format шлюзом не поддерживается и не отправляется.
Проверяются формат, длина, присутствие исходной цитаты в реплике ученика.
feedback содержит до одного исправления original, corrected, explanation и,
если модель его определила, topic. Тема участвует в подборе упражнений.
Для типовой ошибки I wants пояснение дополнительно проверяется локальным правилом.
Пара сообщений записывается одной транзакцией после проверки.

Лимит ответа до 320 токенов, без автоматического повторного платного вызова.
Тайм-аут — 504, недоступность — 503, ошибка формата/связи — 502.
Клиент оставляет введённый текст при сбое.
Тестовый probe check_ai отдельно сохраняет потолок 200 токенов.
Используемая модель — deepseek/deepseek-v4-flash.

## Тест и упражнения

GET /placement/ — 10 вопросов выбранного языка: 5 с вариантами и 5 с вводом слова.
POST /placement/ сохраняет прежнюю структуру request_id + answers.
Ответ дополнен language и band.
0–1 балл — A1, 2–3 — A2, 4–5 — B1, 6–7 — B2, 8–10 — C1.
band: начальный (A1/A2), средний (B1/B2), продвинутый (C1).
Это учебная ориентировочная диагностика.

GET /exercises/?kind=grammar или vocabulary — тренировочные задания текущего языка.
Основная выдача соответствует уровню. Для тем ошибок могут появиться задания
нижних уровней, чтобы повторить базу. Источники тем — последние попытки упражнений
и до 30 последних сообщений ассистента с исправлениями.
POST /exercises/{id}/attempts/ — answer + request_id, прежняя структура результата.
Правильные ответы скрыты до проверки. Нормализуются регистр и пробелы.

## Словарь и внешние источники

/vocabulary/, /vocabulary/{id}/, /vocabulary/review/ и
/vocabulary/{id}/reviews/ сохраняют прежние методы.
Списки относятся к текущему языку. Одинаковое слово можно хранить на разных языках.
Немецкое написание сохраняет заглавную букву; повторный ввод другого регистра
распознаётся как то же слово. Перевод карточки проверяется по эталону.
Интервалы — 1/3/7/14/30 дней после успехов, час после ошибки.

GET /dictionary/lookup/?word=Haus&target=ru
Язык источника берётся из профиля. target — en/de/ru, отличный от источника.
По умолчанию перевод на русский, а для изучения русского — на английский.
Ответ: word, language, target, translation, definitions, examples, source,
source_url, translation_url. Перевод — MyMemory, определения и примеры —
Wiktionary. Примеры могут отсутствовать, интерфейс об этом сообщает.
HTML источника очищается, положительный ответ кэшируется на сутки в процессе.
Лимит — 20 запросов в минуту на пользователя, тайм-ауты фиксированы.
При недоступности переводчика — 503; словарные определения дополнительны.
При переводе отдельного слова на английский первичное словарное значение используется вместо сомнительной пары переводной памяти. Провайдеры и лицензия указаны в интерфейсе.

## Дни, награды и план

GET /statistics/ сохраняет прежние поля и добавляет:
- language;
- activity: today, todayTotal, week (7 дней), weekTotal, streak, lastActive;
- daily_tasks: id, title, to, count, target, xp;
- xp_today;
- achievements: 20 объектов с id, title, description, value, target, unlocked,
  unlocked_at, accent, difficulty;
- learning_plan: шаги с title, description, to;
- focus_topics.

Статистика, график и награды относятся к текущему языку.
Оценка «три языка» учитывает занятия на всех языках.
Даты считаются в Asia/Yekaterinburg. Стрик сохраняется, если занятие было сегодня
или вчера, и сбрасывается после пропуска. Источники — серверные записи, браузерный
журнал не используется. Повтор UUID не создаёт новое действие.

Ежедневные задания: три попытки упражнения (20 XP), три повторения слова (20 XP),
одно добавленное слово (10 XP). XP присваивается за достигнутые цели дня.
Сами цели вычисляются по данным текущего дня, награды сохраняются в AchievementAward.
Полученное достижение остаётся полученным после уменьшения текущего счётчика.
Удаление слова удаляет его повторения из текущих показателей.

Условия наград заданы в learning/progress.py. В исходном планировании дана задача
создать список, отдельный файл с его условиями не предоставлен. В реализации
используются 20 явных условий по словам, упражнениям, повторениям, репликам,
сценариям, стрику, тесту, точности и занятиям на трёх языках.

## Заметки

GET/POST /notes/, GET/PATCH/DELETE /notes/{id}/.
Тело: title (до 120 символов), content (до 5000).
Список относится к текущему языку, запись доступна только владельцу.
