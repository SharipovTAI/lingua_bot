# LinguaBot

Веб-приложение для изучения языков. Отчёт о работе за 1-ю неделю проектного практикума.

## Цель недели

Выполнены две задачи:

1. Настройка проекта — инициализация репозитория и базовая структура.
2. Вёрстка каркаса — основной каркас приложения по макету дизайнера.

Обе задачи закрыты: приложение собирается и запускается локально, каркас экрана совпадает с макетом.

## 1. Настройка проекта

Создано приложение LinguaBot на **React 19**, **TypeScript** и **Vite**.

Базовая структура исходников:

| Путь | Назначение |
| --- | --- |
| `src/main.tsx`, `src/App.tsx` | точка входа и маршруты |
| `src/components/layout/` | шапка, боковое меню, общий каркас |
| `src/pages/` | экраны приложения |
| `src/data/navigation.ts` | пункты меню и тексты разделов |
| `src/index.css` | стили и цветовая система |

Скрипты:

```bash
npm install
npm run dev      # http://localhost:5173/
```

## 2. Вёрстка каркаса по макету

Сверстан основной каркас интерфейса:

- **боковое меню:** логотип LinguaBot, блок «Ваше пространство», пункты Панель, Разговорная практика, Ежедневный урок, Упражнения, Словарь, Заметки, Прогресс, Достижения, Настройки;
- **верхняя панель:** выбор языка (английский), серия занятий, уведомления, профиль пользователя (уровень A2);
- **рабочая область:** контент выбранного раздела.

Главный экран «Панель» свёрстан по макету и содержит:

- блок разговорной практики (чат с ботом, сценарий «В кафе», поле ввода);
- ежедневные задания с прогрессом и XP;
- достижения;
- активность за неделю (минуты практики и график);
- рекомендации;
- инструменты (словарь, заметки, офлайн-упражнения).

Остальные разделы подключены к навигации как заглушки: каркас есть, содержимое будет заполняться на следующих этапах.

**Итог недели:** техническая база проекта готова, визуальный каркас главной панели соответствует макету дизайнера, приложение запускается локально.
