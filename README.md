# LinguaBot

Учебный языковой тренажёр команды «Проектоделы».
Собранный React, Django API и SQLite работают на одном адресе.
За основу интерфейса взята ветка frontend, коммит 85492a5.
Интеграция, сервер и доработки пятой недели находятся в main.

## Открыть готовую демонстрацию

На подготовленном компьютере дважды нажмите **start-demo.cmd**.
Адрес — http://127.0.0.1:8000.

Учебный аккаунт: **demo@linguabot.example**, пароль **LinguaDemo!2026**.
Он содержит помеченные демонстрационные данные, в том числе историю занятий
за три дня для показа графика и стрика. Для занятий с нуля зарегистрируйте
свой аккаунт. Команда seed_demo повторяется без сброса существующего прогресса.

Сервер работает локально через Waitress с DJANGO_DEBUG=false.
Окно браузера можно закрыть и снова открыть: записи остаются в SQLite.
Сборка интерфейса и локальные шрифты обслуживаются WhiteNoise.
Секрет Django создаётся в .runtime/demo-secret.txt.

## Подготовка новой копии

Нужны Python 3.12+ и Node.js 22.12+ с npm.
Проверено на Python 3.14 и Node.js 24.

~~~powershell
git clone https://github.com/SharipovTAI/lingua_bot.git
cd lingua_bot
Copy-Item .env.example .env
python setup_demo.py
.\.venv\Scripts\python.exe start_demo.py
~~~

Если .env уже существует, используйте его. setup_demo.py создаёт .venv,
устанавливает зависимости, собирает React, выполняет миграции, наполняет
справочники и создаёт демонстрационный аккаунт. На Linux путь к Python
в окружении — .venv/bin/python.

Ключ Apimira впишите в APIMIRA_API_KEY локального .env.
В GitHub исключены .env, .runtime, SQLite, окружение Python и сборки.
Ключ остаётся на сервере. Чат делает платный запрос только при отправке реплики.
Лимит чата — до 320 выходных токенов, ограничитель — 10 отправок в минуту.
Автоматического платного повтора нет. Команда check_ai по-прежнему использует
короткий диагностический запрос с собственным потолком 200 токенов.

## Что работает

- Три изучаемых языка — английский, немецкий и русский.
- Отдельные уровни и результаты для каждого языка.
- Десять разговорных сценариев на каждом языке через одну модель.
- Ответы ИИ, исправления с русскими пояснениями и история переписки.
- По 10 вопросов входного теста и 20 упражнений на язык, всего 90 заданий.
- В тесте есть выбор ответа и ввод слова, шкала A1–C1 и три укрупнённые группы.
- Подбор упражнений по уровню, последним попыткам и темам исправлений ИИ.
  При необходимости выдаётся повторение более простого материала.
- Личный словарь, переводы и карточки интервального повторения.
- Внешние MyMemory и Wiktionary: перевод, определения и доступные примеры.
- Серверные график активности, стрик, ежедневные цели и XP за цели.
- 20 достижений с условиями, прогрессом и сохранением даты получения.
- План занятия по уровню, цели, темам ошибок и словам к повторению.
- Заметки, настройки профиля, адаптивная навигация.
- Защита своих данных и повторной доставки результатов через request_id.

Сценарии: знакомство, кафе, магазин, гостиница, ориентирование в городе,
аэропорт, врач (языковая ролевая практика), собеседование, университет,
рабочая встреча.

Результат короткого теста ориентировочный. Проверка упражнений и переводов
карточек использует эталонный ответ. Доступность ИИ и внешнего словаря зависит
от сети и провайдеров. При сбое приложение показывает ошибку и сохраняет
введённый текст. Примеры в словаре зависят от наличия статьи у источника.

## Проверки

~~~powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test
.\.venv\Scripts\python.exe manage.py spectacular --file docs/openapi.yaml --validate
cd frontend
npm run build
npm run lint
~~~

Пройден 81 тест Django. Схема OpenAPI проверена без ошибок.
Через браузер пройдены тест, упражнения, диалог, внешний словарь и повторение
на всех трёх языках, проверены 10 экранов, ширина 390 px и новый вход.
Реальные ответы ИИ в сценарии «Кафе» получены за 3,6–5,6 с.
Повтор UUID вернул сохранённый ответ и не вызвал модель заново.
Линтер React завершился с 7 предупреждениями о структуре эффектов и Fast Refresh.
