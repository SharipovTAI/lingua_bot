# LinguaBot — бэкенд и интерфейс

Учебный проект по практике УрФУ. Исполнитель бэкенда: Шарипов Тимур Илгизович.
Первая неделя: 26.10–01.11.2026. Вторая неделя: 02.11–08.11.2026. Третья неделя: 09.11–15.11.2026.
Четвёртая неделя: 16.11–22.11.2026. Ветка `frontend` содержит интерфейс React и историю `main`.

## Что сделано за четыре недели

- Каркас Django + Django REST Framework, база SQLite.
- Модели и миграция: профиль, сценарий, диалог, сообщение, упражнение, попытка, слово.
- Проверка сервера и соединения с БД: `GET /api/v1/health/`.
- Чтение справочника сценариев из базы: `GET /api/v1/scenarios/`.
- Swagger: `/api/docs/`, схема OpenAPI: `/api/schema/`.
- CORS для React на `localhost:5173` и `localhost:3000`.
- Регистрация по email, проверка пароля, сохранение хеша Django.
- Вход с токеном, выход с отзывом токена, ограничение частоты входа/регистрации.
- Просмотр и изменение своего профиля: уровень, цель, изучаемый язык.
- Создание и список собственных диалогов, сохранение сообщений, загрузка истории.
- Доступ только к своим данным: 401 без токена, 404 для чужого диалога.
- Отдельная команда для проверки доступа к Apimira.
- Ответы ИИ в пяти сценариях с учётом уровня и последних реплик; исправления сохраняются в истории.
- Входной тест из 10 вопросов с сохранением ориентировочного уровня в профиле.
- 20 упражнений по лексике и грамматике, подбор по уровню и ошибкам.
- Личный словарь, проверка переводов, интервалы повторения и статистика.
- Защита записей попыток, теста и повторений от повторной доставки через request_id.
- 62 автоматических теста без обращений к платному API.

API четвёртой недели описан в docs/week-4-api.md.
Интерфейс четвёртой недели: панель по макету, входной тест, упражнения, словарь, достижения. График, ежедневные задания и серия читают `GET /statistics/` и словарь.

## Запуск на Windows

Нужен Python 3.12 или новее. Проект проверен на Python 3.14.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_scenarios
.\.venv\Scripts\python.exe manage.py seed_exercises
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

Открыть http://127.0.0.1:8000/. Без ключа работают авторизация, профиль, справочник, история, входной тест, упражнения, словарь и статистика. Для новых ответов ИИ нужен ключ.
Для существующей копии после обновления повторно выполните `manage.py migrate` и `seed_exercises`. Существующую .env копированием не заменяйте.
`seed_scenarios` можно запускать повторно: записи обновляются без дублирования.
SQLite-файл создаётся миграцией; его не нужно скачивать из GitHub.

На Linux/macOS вместо `.\.venv\Scripts\python.exe` используйте `.venv/bin/python`.

## Запуск React

Django должен быть запущен. Во втором терминале, в этой же папке:

```powershell
npm install
npm run dev
```

Откройте http://localhost:5173/. Для запросов к Django оставьте `VITE_USE_MOCK=false`.
Пароль при регистрации проверяет Django: не короче 8 символов и не слишком простой.
Ключ Apimira нужен только для новых реплик ИИ в чате. Тест, упражнения и словарь его не вызывают.

## Проверка второй недели

Откройте http://127.0.0.1:8000/dev/week2/ при DJANGO_DEBUG=true. Это техническая
страница бэкенда, а не React-интерфейс.

Для прямых запросов API после входа используйте `Authorization: Token <token>`.
Регистрация и вход имеют общий локальный лимит 20 запросов в минуту на IP.

## Проверка Apimira

Впишите ключ в локальный `.env` после `APIMIRA_API_KEY=`.

```powershell
.\.venv\Scripts\python.exe manage.py check_ai --confirm-paid-request
```

Команда делает один платный запрос. Открытие страниц, тест, упражнения и словарь токены не расходуют.
