Проверка регистрации, профиля и истории диалогов (локально, при DEBUG=true)

Что реализовано

  • Регистрация по email и хранение пароля в виде хеша Django.
  • Вход по токену и выход с отзывом токена.
  • Профиль с уровнем и целью изучения английского языка.
  • Создание диалогов, сохранение сообщений и получение истории из SQLite.
  • Доступ только к своим диалогам; документация API для React.
